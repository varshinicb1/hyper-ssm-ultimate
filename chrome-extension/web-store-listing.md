## Full Description

**AI Memory gives ChatGPT, Claude, and Gemini a memory that never forgets.**

Every time you start a new AI conversation, the AI starts from zero. It doesn't remember your name, your project, your preferences, or anything you discussed before.

AI Memory changes that — entirely on your device, no servers involved.

### ✨ What it does

**Auto-save** — Every message in your ChatGPT conversations is automatically saved to memory. A green ✓ shows your memories are being stored.

**Instant recall** — Open the memory panel (🧠 floating button), search for past conversations, and inject relevant context into your current chat with one click.

**Auto-suggest** — As you type in ChatGPT, related memories from the past automatically appear. No searching required.

**Right-click to save** — Select any text on any website, right-click, and choose "Save to AI Memory." Build your personal knowledge base from anywhere.

**Cross-session memory** — A conversation from January is still available in June. Switch between topics, projects, and months without losing context.

### 🔒 Privacy

All memories are stored **locally in your browser** using Chrome's storage API. Nothing leaves your device. No account needed. No data collection.

### 🚀 How to use

1. Install the extension
2. Go to chatgpt.com — conversations are auto-saved
3. Click the 🧠 button to search past memories
4. Click a memory to inject it into your current chat
5. Right-click any text on any page → "Save to AI Memory"

### ❓ FAQ

**Does it work with Claude or Gemini?**
Yes — it works on chatgpt.com, claude.ai, and gemini.google.com.

**How is the memory stored?**
Using a HyperbolicMemoryTree — the same 100% recall algorithm published in our research paper. It's a tree-structured memory that retrieves the exact fact you need in milliseconds.

**Is my data sent anywhere?**
No. Everything stays in your browser's local storage. No servers, no accounts, no data collection.

**How many memories can I save?**
Thousands. Chrome's local storage supports up to 10MB (~40,000 facts).

### 📦 What's included
- Auto-save ChatGPT conversations
- Searchable memory panel
- Auto-suggest as you type
- Right-click context menu save
- Cross-session memory recall

### 🧪 Technical
Built on the ICM (Infinite Context Memory) engine. The same technology benchmarked at 100% recall across 500-turn conversations with ~3.7ms retrieval time. Open source at github.com/varshinicb1/hyper-ssm-ultimate.
