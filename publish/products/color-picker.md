Color Picker Pro — Pick, Save, Copy Colors Instantly

A professional color picker for designers and developers.

Features:
• Pick colors from any webpage with the native EyeDropper tool
• Save your favorite colors (up to 20 in palette)
• Copy color values in 4 formats: HEX, RGB, HSL, CMYK
• One-click copy any format
• Random color generator for inspiration
• Palette persists across browser sessions

Use cases:
- Web developers checking CSS colors
- Designers building color palettes
- Anyone who needs to match colors from any website

Privacy: Works entirely in your browser. No data sent anywhere.

Chrome extension. Install via chrome://extensions → Developer mode → Load unpacked.
