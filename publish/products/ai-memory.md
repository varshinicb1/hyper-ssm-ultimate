AI Memory — Infinite Context Memory for ChatGPT

Tired of ChatGPT forgetting what you told it? AI Memory gives your AI a brain that never forgets.

What it does:
• Auto-saves every ChatGPT conversation (shown with a green ✓)
• Search past conversations instantly
• Inject relevant context into new chats with one click
• Auto-suggest: memories appear as you type
• Right-click any text → "Save to AI Memory" from any website

How it works:
Install → Use ChatGPT normally → Your conversations are saved automatically → In your next chat, open the memory panel → Search → Inject. The AI remembers everything.

Privacy: All memories stay on your device. No servers, no accounts, no data collection.

Compatible with: ChatGPT (chatgpt.com), Claude (claude.ai), Gemini (gemini.google.com)

Technical: Built on the HyperbolicMemoryTree engine — 100% recall accuracy across 500-turn conversations with ~3.7ms retrieval.

Chrome extension. Install via chrome://extensions → Developer mode → Load unpacked.
