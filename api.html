Authentication

Authorization: Bearer icm_sk_xxxxxxxxxxxxxxxx

Endpoints

Save a memory

POST/v1/memories
# Save a fact to the memory tree
curl -X POST https://api.icm-llm.com/v1/memories \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "The secret code is 180X78.",
    "topic": "code"
  }'

Recall memories

POST/v1/recall
# Query memory by topic
curl -X POST https://api.icm-llm.com/v1/recall \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What was the code?",
    "top_k": 5
  }'

List all memories

GET/v1/memories

Delete a memory

DELETE/v1/memories/{id}

Response Format

{

      "topic": "code",
      "similarity": 0.97
    }
  ],
  "latency_ms": 3.7
}

SDK Integration

# Python SDK
pip install icm-llm

from icm_api import ICMClient

client = ICMClient(api_key="icm_sk_...")
client.remember("The secret code is 180X78.", topic="code")
results = client.recall("What was the code?")
print(results[0].content) # "The secret code is 180X78."
