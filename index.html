Two Backends, One Goal

KV-cache replacement that doesn't grow with context length.

⚡

Flat Memory O(1)

Each utterance maps to a point on the Lorentz hyperboloid. A gated recurrence compresses the entire conversation into a fixed 260-byte state. No matter how long the chat, the memory stays the same size.

🌳

Tree Memory O(log N)

Every fact is stored in a hyperbolic B-tree with beam search recall. 100% exact retrieval in logarithmic time. Tested at 500 turns with 3.7ms average latency.

🔌

Any Model, Zero Training

Works with every HuggingFace model. No fine-tuning, no GPU required. Plug it into GPT-2, Llama, Qwen, Phi-3 — just pip install icm-llm.

🗄️

SQLite Persistence

Sessions survive server restarts. Export conversations as JSON or Markdown. Docker deployment in one command.

🔐

Auth & Rate Limiting

Built-in API key authentication with per-key rate limiting. Production-ready for public deployments.

📊

Benchmark Suite

Needle-in-a-Haystack, memory scaling, latency — all runnable with a single command. Tree achieves 100% recall at all context lengths tested.

Try It in 5 Seconds

No account. No GPU. No training.

# Install
pip install icm-llm

# Demo with tree memory (no LLM needed)
icm-demo --memory-backend tree

# Chat with real LLM
icm-chat --model gpt2 --memory-backend tree

# Production server
icm-server --model TinyLlama/TinyLlama-1.1B-Chat-v1.0
